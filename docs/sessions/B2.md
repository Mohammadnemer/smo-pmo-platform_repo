# Session B2

## Session ID

B2

## Scope

Configure the API to support JWT bearer authentication and expose a protected endpoint so authenticated traffic is accepted through the ASP.NET Core pipeline.

## Done when

A signed-in SPA user calls a protected endpoint successfully.

## Prerequisites

- The B1 tenancy middleware and the D1–D4 database foundation must already be present.
- The solution must build successfully with the new authentication plumbing.

## Decisions made

- Added JWT bearer authentication and authorization services to the API via a dedicated authentication extension.
- Registered authentication middleware in the API pipeline before the tenant-resolution middleware.
- Exposed a protected /me endpoint that requires authorization.
- Added regression coverage to confirm unauthenticated requests are rejected.
