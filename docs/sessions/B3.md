# Session B3

## Session ID

B3

## Scope

Add policy-based authorization so role and org-unit-aware access checks protect admin and project-read endpoints in the API.

## Done when

A contributor is denied access to an admin-only route while still being allowed through a project-read route that matches the policy requirements.

## Prerequisites

- The B1 tenant-context pipeline and the B2 authentication middleware must already be present.
- The solution must build successfully with the new authorization behavior.

## Decisions made

- Implemented custom authorization requirements and a handler that evaluates role and org-unit claims.
- Added named authorization policies for admin access and project read access.
- Wired the policies into the API endpoints and added a regression test covering the contributor scenario.

- src/Api/Auth/AuthorizationPolicies.cs
- src/Api/Auth/AuthenticationExtensions.cs
- src/Api/Program.cs
- tests/Platform.Tests/AuthorizationTests.cs
