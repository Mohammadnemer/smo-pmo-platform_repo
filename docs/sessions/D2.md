# Session D2

## Session ID

D2

## Scope

Implement row-level security for the initial platform tables by adding an app.current_tenant_id function and a tenant-isolation policy for each tenant-owned table.

## Done when

A query run without the tenant variable set returns zero rows.

## Prerequisites

- The D1 schema and migration foundation must be present.
- The solution must be able to build with the EF Core migrations path enabled.

## Decisions made

- Added a PostgreSQL RLS function named app.current_tenant_id that reads app.tenant_id from the session context.
- Applied row-level security policies to the D1 tables so tenant data is isolated at the database level.
- Switched the API startup path from EnsureCreated to MigrateAsync so migrations are applied consistently.

## How it was verified
