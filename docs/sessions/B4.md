# Session B4

## Session ID

B4

## Scope

Add the in-process mediator, shared command/domain-event abstractions, and a save-change audit interceptor so state changes can flow through handlers and be recorded automatically.

## Done when

A command runs through a handler and the change lands in the audit log.

## Prerequisites

- The B1–B3 request pipeline, tenant context, authentication, and authorization layers must already be present.
- The platform DbContext and module composition root must already be available.

## Decisions made

- Implemented a hand-rolled in-process message bus in Shared so modules can communicate without project references.
- Added command and domain-event interfaces plus handler contracts in Shared.
- Wired an EF Core SaveChanges interceptor to stamp tenant metadata and create audit entries for persisted changes.
- Exposed a simple strategy creation endpoint in the API that sends a command through the message bus.
