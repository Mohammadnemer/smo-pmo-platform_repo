# Session D3

## Session ID

D3

## Scope

Extend the platform persistence model for the SMO and PMO domains by adding the strategy, initiative, portfolio, program, project, task, dependency, and RAID entities to the schema and wiring them into the shared EF Core model.

## Done when

The solution builds with the D3 schema migration and the new entity set is represented in the Platform DbContext.

## Prerequisites

- The D1 and D2 schema foundation must already be present.
- The solution must continue to satisfy the module-boundary rule that modules only reference Shared.

## Decisions made

- Kept the persistence model architecture-compliant by defining the D3 entities in the Shared layer rather than letting Platform reference the SMO or PMO modules directly.
- Added a migration that creates the SMO/PMO tables with tenant ownership and the expected foreign-key relationships.
- Left the SMO and PMO module-level entity classes in place so each module still owns its domain-facing types while they inherit from the shared base entity.
