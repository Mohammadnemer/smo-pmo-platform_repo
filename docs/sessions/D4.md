# Session D4

## Session ID

D4

## Scope

Add tenant-aware lookup defaults and automatic tenant seeding so a newly created tenant gets sensible BSC perspectives, RAID categories, statuses, and weekday defaults.

## Done when

Creating a tenant seeds sensible defaults automatically.

## Prerequisites

- The D1–D3 schema and migration foundation must already be present.
- The solution must continue to build with the new seeding support.

## Decisions made

- Added a shared lookup entity in the shared domain layer so lookup values can be persisted alongside tenant-owned records without introducing module-to-module references.
- Extended the Platform DbContext with a seed method that creates a tenant and its initial lookup values.
- Wired the API startup path to run the seeding logic after migrations using default configuration values.
